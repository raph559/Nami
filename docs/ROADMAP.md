# Roadmap

## Your list and profile

- [ ] Edit your AniList entry from the app: status, progress (−/+), score, rewatches,
      start/finish dates, notes, remove from list.
- [ ] Long-press an episode: "watched up to here" / "mark as unwatched".
- [ ] Profile page with banner, avatar and stats (episodes, time watched, mean score).
- [ ] Edit your profile: bio, profile color, title language, score format, adult content.
      Avatar and username can only be changed on anilist.co, so Nami links there.

## Anime page

- [ ] Relations graph: prequels, sequels, side stories, spin-offs and films as a graph with
      covers; tap a node to open it.
- [ ] Related anime, recommendations, characters and voice actors.
- [ ] UI polish: featured banner on the home screen, scores on covers, cleaner anime page.

## Player

- [ ] Resume where you stopped, per episode.
- [ ] Skip intros and endings automatically (AniSkip).
- [ ] Autoplay the next episode with a countdown.
- [ ] Picture-in-Picture.

## Subtitles

- [ ] Preferred subtitle language, picked automatically.
- [ ] External subtitles when a release has none in your language (e.g. Jimaku, OpenSubtitles).
- [ ] Subtitle style: size, font, outline/background, position; keep ASS styling when present.
- [ ] Sync offset (+/− ms) per episode.

## More

- [ ] Airing calendar for your list.
- [ ] Notifications when a new episode of an anime on your list airs.
- [ ] Offline downloads.
