# Roadmap

## Your list and profile

- [x] Edit your AniList entry from the app: status, progress (−/+), score, remove from list.
- [ ] More entry fields: rewatches, start/finish dates, notes.
- [x] Long-press an episode: "watched up to here" / "unwatched from here".
- [x] Profile page with banner, avatar, stats and your list by status ("My list" tab).
- [ ] Mean score in the profile stats.
- [ ] Edit your profile: bio, profile color, title language, score format, adult content.
      Avatar and username can only be changed on anilist.co, so Nami links there.

## Anime page

- [x] Relations: prequels, sequels, side stories, spin-offs and films, with
      covers; tap a node to open it.
- [x] Recommendations, characters and voice actors, staff, tags, rankings and scores.
- [x] Trailers, played in the app.
- [ ] UI polish: featured banner on the home screen, scores on covers, cleaner anime page.

## Player

- [x] Resume where you stopped, per episode.
- [x] Skip intros and endings automatically (AniSkip).
- [x] Autoplay the next episode with a countdown.
- [x] Mini-player when you swipe the player down.
- [x] Fill the screen without enlarging the subtitles.
- [x] Picture-in-Picture.

## Subtitles

- [x] Preferred subtitle language, picked automatically.
- [ ] External subtitles when a release has none in your language (e.g. Jimaku, OpenSubtitles).
- [x] Subtitle style: font, outline/background, position; keep ASS styling when present.
      Size is done.
- [x] Sync offset (+/− ms) per episode.

## More

- [x] Airing calendar for your list.
- [ ] Notifications when a new episode of an anime on your list airs.
- [x] Offline downloads, with a queue, quality choice, Wi-Fi only and a speed limit.
